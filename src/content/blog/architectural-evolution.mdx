# One Week, Three Architectures

Seven days ago, I had a static resume and a collection of scattered scripts. Today, I have a **Federated System Hub** operating a "Dual Hub" strategy with isolated production pipelines.

This wasn't a multi-year transformation. It was a single week of vacation, fueled by a desire to experiment with **Advanced Agentic Coding**.

## The Goal: "Enterprise Rigor, Hacker Fun"

I wanted to prove a point: You can apply enterprise-grade discipline (GitOps, Infrastructure-as-Code, Containerization) to personal projects without killing the joy of experimentation.

The challenge was **Speed vs. Complexity**. Building a custom Kubernetes-like platform on Raspberry Pis usually takes months. I wanted it done before my coffee grew cold.

## The Evolution

In just 168 hours, we iterated through three distinct architectural phases:

### Phase 1: The Disconnected Polyrepo
Every project was an island. My resume was a Vue app; my game prototypes were raw HTML.
*   **Problem**: No shared identity, no common infrastructure.

### Phase 2: The "Hybrid-Mono" Experiment
I attempted to stitch everything together using Git Submodules and a "Monster Hub".
*   **Result**: "It worked until it didn't."
*   **Lesson**: Tying a Game Jam prototype's build pipeline to a Professional Resume's deploy cycle is a recipe for frustration.

### Phase 3: The Federated Solution (Dual Hub)
We landed on a separation of concerns that mirrors micro-frontend architectures I've managed at scale:

1.  **Professional Hub (`kelvinbward`)**: Built with **Next.js**. Strict governance, type safety, and clean lines.
2.  **Creative Hub (`goobface`)**: Built with **Astro**. A chaotic playground for Phaser.js and Three.js physics experiments.
3.  **Shared Infrastructure**: Both consume the same private cloud resources (PostgreSQL, Gateway) via a standardized "Engine Room" repo.

## The Agentic Difference

This refactor wasn't a solo effort. It was a **Pair Programming** session with AI.

We didn't just generate code; we debated architecture. I provided the "Commander's Intent"—the vision of a professional-yet-creative dual identity—and the Agent handled the tactical execution of Dockerfiles, GitHub Actions, and CSS variables.

This underscores a shift in how we build. The "Senior Engineer" is no longer just a code writer, but an **Architect of Context**, guiding capable agents to manifest complex systems in record time.
